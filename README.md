# 穿石 Stoneflow 回测实验室

**沿时间回放交易，让每一笔决策都有据可查。**

穿石 Stoneflow 是一个面向A股日频策略研究的回测实验室。它将行情回放、策略信号、模拟成交和账户核对串联起来，让策略既能运行，也能逐笔检查。

目前的研究围绕两个问题展开：近期跌幅较大的股票，之后是否会反弹？突破近期高点的股票，上涨能否延续？实验从长源东谷与科大讯飞的个股对照，扩展到课程数据中5,451列证券的动态股票池，比较策略在不同股票、年份、仓位和交易成本下的表现。

仓库提供**读取Feather行情、可重新运行策略的本机研究工作台**，以及**无需原始数据即可阅读的独立网页报告**。

## 实验室能力

| 模块 | 能力 |
| --- | --- |
| 模拟时钟与数据 | 逐日回放行情，历史窗口截至当前时点；使用cumadj统一价格信号口径 |
| 可编程策略 | Python状态型策略接口，支持自定义条件、内部状态和目标持仓 |
| 模拟券商 | 次日执行、涨跌停限制、T+1、资金检查、费用和滑点，记录成交与拒单 |
| 账户与对账 | 保存现金、持仓、订单、信号和每日权益，标记缺价与旧估值；精度账户分别记录原始股份、股利应收与送转锁股，支持独立账本重放 |
| 研究工作台 | 本机网页、参数调整、分股比较、净值与回撤、运行历史和报告导出 |
| 研究验证 | 同口径对照、训练期选型、分年分析、成本压力检验、股票分组与损益归因 |

当前支持日频、多头、目标仓位策略。个股趋势实验使用原版复权单位账户；全股票池研究使用原始股份精度账户。两类实验的区间和执行模型不同，分别报告结果，收益不直接拼接。

### 全股票池：5DR与20日突破

<a id="homework"></a>

主评价区间为 **2025-01-02至2026-09-30，共424个交易日**。在课程5,451列证券中，按逐日历史ST状态与已有行情筛选，排除ST／*ST和未知状态的新买入；课程名单是否覆盖完整历史市场仍有数据边界。

5DR比较基础策略与4个改进，20日突破比较5个候选并补充固定半仓诊断。两个策略家族各自仅用2024年选型，冻结后在评价期比较，不重新挑选评价期冠军。

| 策略家族 | 方案 | 累计收益 | 最大回撤 |
| --- | --- | --- | --- |
| 5DR | 基础：每日选过去5日收益最低20只 | 2.76% | -56.50% |
| 5DR | 流动性过滤【2024冻结】 | 37.55% | -47.17% |
| 20日突破 | 普通20日突破 | -23.19% | -43.87% |
| 20日突破 | 趋势＋ATR仓位与退出【2024冻结】 | -11.71% | -22.75% |

**5DR的改善伴随较高风险。** 流动性版在本区间盈利，但仍有47.17%的最大回撤；2026年前三季度亏损20.71%，双倍费用滑点后全期仅获利0.73%。共同股票池的信号检验也未证明稳定正超额，不能把本样本盈利等同于普遍有效。

**突破的回撤下降需要结合仓位解释。** 趋势＋ATR版仍然亏损；固定半仓普通突破反而取得3.14%收益、-19.02%回撤，本次无法把防守版的改善全部归因于ATR。

**股票特征影响结果，但跨期表现仍不稳定。** 按2024资料固定的较高波动股票组，普通突破全期收益19.38%、回撤-31.06%；仅用2025选组、2026重新建账后只获利0.36%、回撤-30.23%。[扩展研究](ANALYSIS_STRATEGIES.md)同时保留损益归因、共同股票池信号检验和全部7个固定股票组，不将事后盈利股票当作未来适用名单。

### 个股对照：长源东谷与科大讯飞

<a id="classroom"></a>

以长源东谷603950.SH、科大讯飞002230.SZ为研究对象，比较普通20日突破、成交额确认突破与买入并持有。初始总资金100万元，两股各使用50万元独立子账户，不互相挪用现金；共同评价区间为 **2020-07-01至2026-10-16，共1,526个交易日**。

空仓时，复权收盘价突破此前20日最高复权high，产生买入信号；持仓时，跌破此前10日最低复权low，产生退出信号。窗口不含当天，信号产生后于次日开盘尝试成交。确认版再要求当日成交额大于此前20日平均成交额的1.5倍。持仓期间保留股数，不每日重置权重。

| 方案 | 两股组合累计收益 | 最大回撤 |
| --- | --- | --- |
| 普通20日突破 | -25.66% | -41.84% |
| 成交额确认突破 | -8.52% | -39.13% |
| 买入并持有 | 87.03% | -47.41% |

这些是原版复权单位账户、保守涨跌停代理下的教学结果。成交额确认减少了本样本的组合亏损，但没有超过买入并持有；个股改善也不一致：长源东谷略有恶化，科大讯飞有所改善。[完整实验报告](REPORT.md)保留六个独立子账户、持仓时间与逐笔记录。

## 开始使用

Python 3.10+，推荐3.12。在仓库目录执行：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python web_server.py --data-dir /你的路径/feathers
```

打开 http://127.0.0.1:8765 。只绑定本机，不上传行情、不连接券商，也不发送真实订单。

`/`为个股研究工作台，`/5dr`与`/breakout`分别展示已保存的全池反转与突破研究。原始Feather及辅助历史数据缓存不随仓库分发；全池研究的完整复现需按各自指南准备辅助数据。

课程数据从[第四讲issue](https://github.com/aslan9/pku_quantllm/issues/8)下载。也可以将七个文件放入`data/feathers/`，再直接`python web_server.py`。本机已有的`local_config.json`可记录数据路径，此文件及原始Feather不进入Git。完成依赖安装后，macOS也可双击`Start.command`启动。

网页可选择三组研究或等权流程演示、调整区间/资金/费用/滑点、导入精确涨跌停CSV、切换成交模式、查看净值/回撤、分股比较、成交/拒单/持仓、运行历史并导出报告。

## 扩展策略

引擎接收独立Python对象的`on_close(context)`。策略可以保存内部状态、结合多个行情字段、检查真实模拟持仓、实现任意条件和返回目标仓位；不需要改动引擎。突破策略在持仓时只判断退出条件，未触发时保持原持仓，不每日重置权重；订单失败后按照实际持仓继续判断。

```python
class MyStrategy:
    def on_close(self, context):
        history = context.history('close', lookback=21, adjusted=True)
        # 在这里编写状态、组合条件或自己的模型。
        return None   # 保持原持仓
        # return {}   # 下一次开盘尝试清仓
        # return {'603950.SH': 0.5}  # 下一次开盘尝试达到目标权重
```

`None`表示不下新指令；权重映射表示新目标，省略的证券目标为0。历史接口只返回截至当前日期的副本。当前通用范围是日频目标仓位策略；没有盘中事件、限价单撤改、做空、保证金或完整实盘订单生命周期。复杂策略逻辑可扩展，不等于已实现全部交易机制。

## 账户模型与成交边界

个股趋势实验使用 `BacktestEngine`，结果位于`results/research/`；全池5DR与突破研究使用 `PrecisionEngine`。后者按原始股份、现金、股利应收和送转锁股分别记账，并加入历史ST、参考前收、数量单位及滞后成交额容量检查，详见[5DR精度说明](docs/PRECISION_5DR.md)和[突破精度说明](docs/PRECISION_BREAKOUT.md)。日线盘口、ST公告时点、个税与特殊公司行为仍有精度边界。

以下说明原版个股实验的执行口径：

**复权单位账户。** 价格比较使用原价×cumadj/固定基准因子，成交检查保留原价。累计因子无法还原每次现金分红、送股、配股与到账日，所以持仓输出为复权单位和模型等价股数，不能当作券商登记股数；没有虚构现金分红账本。

**涨跌停资料不足。** `strict`模式需要外部精确涨跌停资料；缺资料拒单。资料齐全时涨停拒买、跌停拒卖。`conservative`模式按因子近似还原参考前收，以向内一分钱的5%边界保守保护，可能过度拒单，也不能证明识别所有历史涨停。个股实验的网页与报告持续标明代理，其绩效为代理下的教学结果，不能宣称精确成交复现。

另外，全天成交额非正或缺失的日期，会**事后否决成交**。全天零成交额是执行不可行性的证明，属于日线执行检查，不作为盘前可获知的选股信息；未使用当日高低收盘价回头决定开盘成交。严格的逐事件实盘验证仍需盘前停牌资料与更细粒度数据。

费用：佣金万三、最低5元、滑点5bps；卖方印花税在2023-08-28前后分别千分之一/万分之五。暂未覆盖全部过户等收费。每个子账户98%目标投资比例；期末不强制清仓。

## 研究背景与课程要求

本项目起源于北京大学量化交易系统第四讲“回测”的系统建设与策略研究练习，后续扩展为全股票池研究。课程数据与背景见[第四讲issue](https://github.com/aslan9/pku_quantllm/issues/8)。

| 课程要求 | 项目对应实现 |
| --- | --- |
| 建设回测系统，支持更复杂的策略 | 模拟时钟、可编程状态型策略、模拟券商、订单／持仓／现金记录及本机网页 |
| 选择两只股票研究策略 | 长源东谷与科大讯飞；普通突破、成交额确认突破、买入持有及六个独立子账户 |
| 使用累计复权因子 | high、low、close等价格信号使用cumadj转为一致口径；执行限制按原价检查 |
| 不能假定涨停可以买到 | 涨停拒买、跌停拒卖；停牌、零成交额与资料缺失按执行模型处理 |
| 指定范围、排除风险警示股票 | 全池主研究为2025-01-02至2026-09-30；按历史状态动态排除ST／*ST及未知状态的新买入 |
| 改进5DR并关注回测精度 | 训练期选型、分年与成本压力检验、原始股份账户、公司行为处理及独立账本重放 |
| 延续突破研究，判断适用股票 | 趋势与ATR对照、固定半仓参照、2024特征分组、2025选组后2026重新建账 |

## 文件结构

- `backtest/`：数据、时钟、策略接口、突破策略、券商、撮合限制、统计与导出。
- `research.py`：六个独立子账户和三组研究汇总。
- `web_server.py`、`web/dist/`：本机API与暖纸色网页。
- `report_site/`：无需服务的网页报告首页、5DR、突破、完整报告和机制分析；本机打开或由Pages托管均可。
- `build_report_site.py`：仅用Python标准库，从已保存报告打包上述站点，不重新回测。
- `research_5dr.py`、`research_breakout.py`：同区间全池反转与突破研究，2024选型、评价、压力情景及归因诊断。
- `tests/`：71项测试，涵盖两个引擎、状态型策略、复权、分红、送转锁股、因果性和网页任务。
- `strategy_analysis.py`、`results/strategy_analysis/`：收益来源、股票分组与跨期研究。
- `results/5dr_review/`、`results/breakout_review/`：全池研究的派生结果、逐笔账本、独立HTML报告与校验。
- `results/final_review/`：单元测试日志、账本重放与文档核对记录。
- `results/research/`：研究指标、每日资产、订单、持仓、信号和子账户记录。
- `examples/daily_limits_TEMPLATE.csv`：精确资料模板，`date,symbol,upper_limit,lower_limit,no_limit,suspended`。
- `.github/workflows/tests.yml`：GitHub Actions测试；不依赖未上传的课程行情。
- `.github/workflows/report-pages.yml`：手动发布只读报告的Pages工作流，不随push自动发布。

原始数据、虚拟环境、本机路径配置、临时网页运行历史均已忽略。仓库提供代码与派生研究记录，源数据请使用课程提供的下载链接。

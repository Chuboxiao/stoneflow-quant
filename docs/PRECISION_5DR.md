本次评价区间固定为2025-01-02至2026-09-30。2024年用于选型，2023年9月起的前置行情仅用于指标预热。`REVIEW_5DR.md`是最终审核入口，原`REPORT.md`保留最早的双股票突破研究。

## 完整重跑

使用Python3.12，先在仓库目录创建并激活虚拟环境：

```bash
python -m pip install -r requirements-research.txt
python research_5dr.py --data-dir /你的路径/feathers --register-only
python tools/fetch_reference.py --data-dir /你的路径/feathers
```

辅助历史数据来自BaoStock，默认4个进程、分批缓存，网络时间通常比回测本身长。按证券、日期读取未复权`close,preclose,tradestatus,isST`；下载失败不会被当作“非ST”。重跑下载命令会跳过已成功缓存的文件。辅助源数据与课程Feather一样保存在Git忽略的`data/`内。

首先发现实际持有期间需要核对的公司行为，再补充事件：

```bash
python research_5dr.py --data-dir /你的路径/feathers --output work/5dr_discovery --provisional
python tools/fetch_actions.py --requests work/5dr_discovery/needed_actions.json
```

重复上述两条，直到发现文件为空。发现模式只用于确定缺什么资料：会暂用合成数量跟踪未解释的因子变化，因此它的收益不能作为提交结果。公司行为数据按除权年份、证券缓存；已成功的事件不会重复下载。若某个已下载事件仍不能解释变化，应核对数据或特殊公司行为，不能不断重试后忽略问题。

正式运行不允许缺失事件兜底：

```bash
python research_5dr.py --data-dir /你的路径/feathers
python validate_5dr.py
python -m unittest discover -s tests -v
python make_5dr_report.py
```

输出`results/5dr_review/`包括5个2024训练账户、5个评价账户、基础与冻结方案的压力场景、每日净值／订单／持仓／信号／公司行为／估值调整、选型文件、覆盖率和独立账本校验。完整源数据哈希与下载清单用于检测复现输入是否发生修订。不要将发现模式输出覆盖到正式结果目录。

另有长源东谷与科大讯飞的6个同区间对照子账户：原突破、成交额确认、买入持有，均使用新账户模型，各50万元，不用于5DR选型。

`reference/corporate_reference_overrides.json`保存4笔已核对的差异化分红送转公告摘要。因回购专户不参与分配，普通持有人实际获得的现金与股份比例，不一定等于市场除权价使用的公司总股本摊薄比例。引擎分别使用这两组数据，不为消除校验差异随意放宽容差；摘要记录公告日期、实施日期和原始PDF来源。

沪深300仅作价格指数参考，不参与选型。缺少指数缓存时报告会注明，不能伪造参考曲线。需要补充时通过BaoStock下载`sh.000300`未复权日线`date,code,close`，覆盖2023-09-01至2026-09-30，保存为`data/reference/csi300.csv`。

## 策略接口

精度引擎保留任意Python策略对象的`on_close(context)`接口，提供截止当前收盘的行情和历史状态副本：

```python
class MyStrategy:
    def __init__(self):
        self.last_signal = None

    def on_close(self, context):
        closes = context.history('close', lookback=21, adjusted=True)
        risk = context.states('isST', lookback=1).iloc[-1]
        # 这里可以调用自己的函数、模型，保存状态或使用 context.positions。
        # positions 在新引擎中是原始股份数量（含已确认但尚锁定的新增股份）。
        return None  # 不产生新的订单计划
```

返回权重映射表示新目标，省略的持仓目标为0；返回`{}`表示产生退出计划。权重不得为负或超过总额1；所有策略仍必须经过同一券商限制。内置5DR使用预先计算的滚动特征，计算只用当日及以前数据，前缀因果性由测试验证。引擎没有盘中回调、委托撤改、做空或保证金。

## 精度范围

| 项目 | 实现与限制 |
| --- | --- |
| 股票池 | 课程5451列的当日可用子集；未知ST/停牌状态不入选，不能证明源包覆盖完整历史市场 |
| 时间 | 前一日收盘固定股数；次日开盘附近顺序成交代理，先卖后买；不声称同一集合竞价同时撮合 |
| 复权 | 价格×cumadj计算5日收益；账户按原始股份与公司行为明细记账，不凭累计因子增加真实股份 |
| 现金股利 | 登记日确认权利、派息日到账；统一20%预扣是保守假设，未逐批复原个人持股期限税率 |
| 送转 | 新增股份向下取整；提供上市日时锁定，缺日按除权日的假设会计数；配股、重整和完整零股分配未全部覆盖 |
| 因子变化 | 除权日取消旧计划；持仓变化无对应事件则正式运行停止 |
| 涨跌停 | 历史前收＋板块与日期规则，十进制四舍五入；仍非交易所逐日官方限价文件，特殊无涨跌幅情形不保证完整 |
| ST时点 | 用历史生效日标记，假设盘前已知；没有公告发布时间和当时数据版本快照 |
| 股数 | 主板/创业板100股；科创板最少200股、之后1股递增；完整余股退出、T+1、送转锁股；单笔上限统一5万股 |
| 容量 | 事前按上一日已知的近20日平均成交额限制，默认1%；不据当天总额推断开盘容量 |
| 日线否决 | 全天无成交、滑点价超出当日高低等只否决不可能的成交，不能证明通过检查的订单必然成交 |
| 缺价 | 先保留旧估值并标记，连续20日缺价减记0；股数保留，不变成卖出现金，另跑旧估值敏感性 |
| 费用 | 佣金万三最低5元、卖出万五印花税、双边十万分之一过户费、单边5bps滑点；佣金视为含经手等收费 |
| 评价 | 2024选型，2025—2026不重新选冠军；这是回顾性时间隔离，不是真正前瞻实盘 |

不要只引用一个收益数字而删掉相应模型说明。也不要把“测试通过”解释成市场数据、公告时点和真实盘口成交已全部得到验证。

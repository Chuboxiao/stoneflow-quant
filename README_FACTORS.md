# 因子评价 · 穿石 Stoneflow

[实验室总览](README.md) · [回测系统](README_BACKTEST.md) · [策略研究](README_RESEARCH.md) · [启动指南](docs/START.md)

新增 **因子改进**：在现有评价能力上创建可持续研究的实验，保存多家族候选、失败反馈、组合增量和冻结结果。入口为[本机因子改进](http://127.0.0.1:8765/factors/improve)，操作和第六讲实验见[因子改进说明](README_EVOLUTION.md)。

因子评价回答“分数高的股票，未来是否表现更好”；策略回测回答“把分数按规则变成订单后，扣除成本还剩多少收益”。两者在同一实验室内并列展示，不把策略收益／回撤评分当作IC。

内置 **5DR、20日动量、20日突破幅度、成交额放大、20日低波动**。也可导入`date,symbol,value`长表CSV，或编写只读取截至当前收盘历史的Python因子。原有策略接口保留，新`FactorPortfolio`还可把其他因子接入同一个原始股份回测引擎。

首个完整演示使用5DR：分数为过去5日复权收益率的负数，高分代表近期跌得多。基础池与流动性池分别评价，所有未来报价终点不晚于2026-09-30。

| 5DR，未来5交易日报价标签 | 基础非ST池 | 加流动性过滤 |
| --- | --- | --- |
| 平均Rank IC | 0.0283 | 0.0281 |
| 2025年信号的平均Rank IC | 0.0493 | 0.0489 |
| 2026年前三季度信号的平均Rank IC | -0.0009 | -0.0009 |
| Q5−Q1平均未来5日报价收益 | 0.0755% | 0.0759% |

本样本中，流动性过滤没有明显提高这一期限的Rank IC；2026年相关性也没有保持2025年的正方向。原净交易收益的改善不能直接解释为“因子预测能力增强”。Q5约含股票池最高分20%的证券，净交易账户则选20只，两者不是同一个组合；分组报价未扣费、不保证涨停可买，不能当作净交易结果。

默认评价五个内置因子，并为5DR重跑基础／流动性两池的标准和双倍成本账户。仅评价其他因子的预测能力不要求公司行为资料；净交易回测缺必要资料时停止。历史ST未知状态始终排除，不按当前股票名单回填历史。

## 从网页开始

1. 按[启动指南](docs/START.md)打开实验室，点击顶部的“因子观测台”。
2. 先选“5DR · 五日反转”、基础池、未来5个交易日，阅读IC、五分组与分年表现。
3. 切换流动性池，观察过滤条件对预测统计和净交易账户分别产生什么变化。
4. 切换其他因子或预测期限；需要新实验时展开“运行新的因子评价”，设置区间后运行，也可导入CSV。
5. 导出IC、分组与覆盖明细，并连同参数、来源和账户约束一起保存。

## 三层评价

| 层次 | 看什么 | 回答什么 |
| --- | --- | --- |
| 预测能力 | IC、Rank IC、ICIR、分组单调性和1／5／10／20日表现 | 因子分数能否区分未来收益？ |
| 稳定性 | 分年／月度、预测期限、标签覆盖、缺价、名单换手和因子间相关性 | 效果是否持续，是否依赖特殊条件？ |
| 交易表现 | 扣费累计／年化收益、回撤、换手、拒单、成本压力和收益／回撤评分 | 采用具体交易规则后表现如何？ |

分组曲线使用报价，净交易曲线使用原始股份账户，两者在页面中分别标注。原收益／回撤分数保留在交易层；累计、年化及2024选型期与2025—2026评价期的核算见[策略研究的收益口径](README_RESEARCH.md#如何读收益和选型分数)。

## 评价自己的因子

- **CSV**：导入`date,symbol,value`长表，数值须在对应收盘时已知。参考[CSV格式样例](examples/factor_values_TEMPLATE.csv)，样例中的两行虚构数值只用于说明格式。
- **Python**：实现`FactorSpec`与时点builder。参考[10日反转示例](examples/custom_factor.py)，通过`--plugin`加载可信本机代码。
- **净交易**：`FactorPortfolio`将分数送入现有`PrecisionEngine`；`--trade`会实际运行交易账户，需要公司行为资料。

[详细方法与扩展接口](docs/FACTORS.md)集中维护公式、数据要求、同分分组、缺失标签、HAC诊断和模型边界；[设计与扩展约定](docs/DESIGN.md)说明新增功能应该放在哪里。
